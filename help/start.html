使い方ガイド 更新 2026.09.07

はじめてガイド

この章では、お店の登録から商品設定・テスト予約・受付開始までを順番に進めます。スマホでもパソコンでも使えます。

商品名・サイズ・税込価格・写真、定休日・受取時間・締切・1日の台数上限を手元に用意してください。

1. お店を登録する#

  1. 新規登録ページを開きます。
  2. 店名を入れます。お客様にも表示される名前です。
  3. **店舗ID（予約ページのURLになります）**を入れます。英小文字・数字・ハイフンで3〜30文字です。先頭と末尾は英数字にし、ハイフンを2つ続けないでください。
  4. 住所を入れます。
  5. 電話番号を入れます（任意）。
  6. メールアドレスを入れます。ログインと予約通知に使います。
  7. **パスワード（8文字以上）**を入れます。
  8. 利用規約・プライバシーポリシーを確認します。
  9. 同意のチェックを入れます。
  10. **「登録してお支払い登録へ進む」**を押します。

💡 店舗IDは予約ページのアドレスの一部です。後から管理画面で変更する機能はありません。

2. カードを登録する#

  1. 表示されたお支払いページでカード情報を入れます。「お支払い登録がまだ完了していません」と出た場合は、**「お支払い登録へ進む（7日間無料）」**を押します。
  2. お支払いページに表示された金額・無料期間を確認します。
  3. ページの案内に沿って登録を完了します。
  4. 完了画面の **「管理画面をひらく」**を押します。

カード登録完了から7日間が無料期間です。終了後は月額4,980円（税込）の決済が始まります。終了日は管理画面の「ご契約・お支払い」で確認できます。詳しくはご契約とお支払いへ。

3. 管理画面の開き方を覚える#

管理画面をブックマークしておきます。次回からはメールアドレスとパスワードでログインします。

スマホでメニューが見えない場合は、右上の **「☰」**を押します。

4. 予約を受けるルールを設定する#

  1. メニューの **「設定」**を開きます。
  2. **「店舗の基本情報」**で店名と予約通知メールを確認します。
  3. **「定休日」**で休む曜日を選びます。
  4. **「基本の締切」**に、受取日の何日前まで受け付けるかを入れます。
  5. **「締切日の受付時刻」**を入れます。
  6. **「締切日数の数え方」**を選びます。
  7. 画面下の **「保存する」**を押します。
  1. **「1日の上限（全体）」**に合計台数を入れます。初めて設定する場合は **「この上限にする」**を押します。設定済みの数字を書き替えた場合は **「保存する」**を押します。
  2. **「受取時間」**で開始・終了の時刻を入れます。
  3. 「1時間ごと」など、時間の間隔を選びます。
  4. **「まとめて追加」**を押します。
  1. **「お客様への案内とセルフ操作」**に、お店のキャンセルポリシーと特定商取引法に基づく表記を入れます。
  2. お客様ご自身での変更・キャンセルを使う場合は **「有効にする」**にチェックを入れます。
  3. それぞれの操作期限を確認します。
  4. **「保存する」**を押します。

💡 追加・削除などは、その場で反映する操作があります。画面下の保存バーの案内も確認してください。詳しい設定は受付のルール・設定にあります。

5. 商品を1つ登録する#

  1. メニューの **「商品」**を開きます。
  2. **「＋ 新しい商品を追加」**を押します。
  3. 商品名を入れ、**「OK」**を押します。
  4. **「基本情報」**で説明・写真・注意書きを入れます。
  5. **「締切」**を確認します。お店の基本の締切に合わせる場合は、この商品の締切欄を空欄にします。
  6. **「サイズと価格」**まで進みます。
  7. サイズ名と税込価格を入れます。
  8. **「追加」**を押します。サイズが複数ある場合は繰り返します。
  9. お客様に選んでもらう項目があれば、選択グループを作ります。プレートの文字などは共通の質問で作れます。
  10. **「保存する」**を押します。
  11. **「公開する」**を押します。

選択肢・質問・画像・季節商品は商品を登録するに手順があります。

6. 自分でテスト予約する#

  1. 商品画面の **「お客様画面を見る」**を押します。お店の予約ページが別の画面で開きます。
  2. 商品とサイズを選びます。
  3. 必要な選択肢と質問に回答します。
  4. 受取日・時間を選びます。
  5. テスト用のお名前と、自分のメールアドレスを入れます。
  6. **「入力内容を確認する」**を押します。
  7. 商品・日時・金額・案内文を確認します。
  8. **「この内容で注文する」**を押します。
  9. お客様用の確認メールと、お店用の予約通知が届いたことを確認します。
  10. 管理画面でテスト予約の 受取日を選びます。
  11. **「受取リスト」**に予約が表示されたことを確認します。
  12. **「製造ケーキ一覧」**で台数と注文内容を確認します。
  1. 確認メールの専用リンクを開きます。
  2. **「このご予約をキャンセルする」**を押します。
  3. **「キャンセルを確定する」**を押します。
  4. 管理画面で **「キャンセル」**になったことを確認します。

キャンセル後も記録は残り、予約枠は戻ります。専用リンクの期限を過ぎた場合やセルフ操作を無効にしている場合は、受取リストの予約カードからキャンセルします。

7. 商品をそろえて受付開始する#

  1. 受付する残りの商品を登録します。似た商品は **「この商品をコピー」**で作れます。
  2. コピーした商品の名前・価格・選択肢を確認します。
  3. 準備できた商品を公開します。
  4. お客様画面で品ぞろえ・価格・予約できる日を確認します。
  5. 予約ページのアドレスをコピーします。「商品」の管理画面のアドレスと取り違えないようにしてください。
  6. Instagram・ホームページ・LINE公式などに予約ページのリンクを載せます。

スタッフには毎日の早見表を共有してください。

うまくいかないとき#

困りごと 確認するところ
商品が出ない 公開状態・販売期間・ページの再読み込み
日付が選べない 定休日・締切・上限・受取期間
メールが届かない 迷惑メールフォルダ・通知先・メール未送信の表示
テスト予約が見つからない 受取リストの日付が、テストで選んだ受取日になっているか

詳しくは困ったときを開いてください。
